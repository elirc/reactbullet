# Mission Learning Path

This suite is a training campaign, not passive documentation. Every mission forces tracing, interpretation, and explanation.

## How The Mission System Works

1. Complete missions in order.
2. Open the exact files/lines listed.
3. Read annotated snippets first, then full file context.
4. Answer Socratic questions from memory.
5. Self-grade immediately using rubric criteria.

## Pacing Recommendation

1. Week 1: Missions 1-8 (Junior fundamentals).
2. Week 2-3: Missions 9-17 (mid-level system reasoning).
3. Week 4+: Missions 18-24 (ownership and risk posture).
4. Ongoing: Mission 25 reference docs while implementing features.

## How To Self-Grade

Strong work means:

- You can explain a path end-to-end with file/line evidence.
- You can predict failure modes before reproducing them.
- You can review changes for risk, not only correctness.

## How This Suite Differs From Normal Docs

- Normal docs optimize for understanding.
- These missions optimize for capability under pressure.
- Each mission is intentionally scoped to one engineering muscle at a time.
